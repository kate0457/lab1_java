# РАБОТА С МАТРИЦАМИ КОМПЛЕКСНЫХ ЧИСЕЛ


## Возможности
- **Сложение** и **вычитание** матриц одинакового размера
- **Умножение** матриц (с проверкой совместимости размеров)
- **Транспонирование** матрицы любого размера
- **Определитель** квадратной матрицы
- **Обратная матрица**
- **Деление** матриц (A / B = A × B**(-1))
- Ввод комплексных чисел в формате 'x+yi' (4+5i, 3, -2-i, i)

## Структура проекта
'Complex.java' - Класс комплексного числа с арифметикой (add, subtract, multiply, negative, divide)
'Matrix.java' - Класс матрицы комплексных чисел с операциями 
'Operation.java' - Enum со списком доступных операций
'lab1.java' - Главный класс с консольным интерфейсом

## Как запустить
Через lab1.java, открыть и нажать Ctrl + Shift + F10
